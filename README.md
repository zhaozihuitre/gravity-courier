# 引力信使 · Gravity Courier

**在线玩**：https://zhaozihuitre.github.io/gravity-courier/ （GitHub Pages，电脑和手机都能打开）

借行星引力让鱼雷拐弯，击毁躲在星球背后的星际海盗船。纯 HTML5 Canvas，不依赖任何库，浏览器和手机都能玩。

## 怎么玩

直接用浏览器打开 `index.html`（双击即可，不需要服务器）。

- **瞄准**：在屏幕任意位置拖动（像拉弹弓，往后拉），瞄准会一直保留；松手不会发射。触屏灵敏度为 0.6 倍，方便微调。
- **微调**：角度 ↺↻ 每次 0.5°、力度 −/+ 每次 1%，按住可连续调整。
- **发射**：点「发射」键（横屏在右侧，竖屏在底部）。飞行中这个键变成「按住加速」，按住屏幕也能 3 倍速。
- **快捷键**：`←→` 角度（`Shift` 精调 0.1°），`↑↓` 力度，`空格/Enter` 发射，`R` 重来，`Esc` 暂停。
- **求助**（右上角两个图标，默认可用；想改成失败 3 次后才出现，把 `js/game.js` 里的 `HELP_AFTER` 改成 3）：
  - **呼叫预警机**（飞机图标）：一架预警机飞过星区，雷达扫过之后，辅助线变成鱼雷的完整轨迹，并把海盗（包括移动中的）和民船一起算进去。按当前瞄准此刻发射能命中时，线变绿、圈出命中点，「发射」键也变绿；会打到民船时显示红圈。角度、力度和时机都由玩家自己调。本次最多 2 星。
  - **自动瞄准**（瞄准镜图标）：准星在海盗之间搜索，锁定后自动把瞄准转到一条能命中的航线，并画出航线和命中点。发射仍由玩家按：移动目标的关卡，「发射」键会倒计时，变绿（「现在发射！」）时按下就能命中；按早了会提示早了多少，错过窗口会重新锁定。本次最多 1 星。
- **语言**：中文 / English。第一次打开按系统语言自动选择，标题页和暂停菜单里可以切换，选择会被记住。
- **物理小卡片**：12 章各一张，讲这一章用到的真实物理原理、公式和真实世界的例子（旅行者 2 号的引力弹弓、苏梅克-列维 9 号彗星、DART 撞击小行星等）。每章第一次通关时自动弹出，之后在选关页的「物理小卡片」按钮可以重看。
- **震动**：爆炸时手机会震动，按爆炸大小区分强弱（Android 浏览器支持，iOS Safari 没有震动接口）。标题页和暂停菜单里可以关掉。
- **难度曲线**：前期海盗船更大（命中半径 1.8 倍）、预测线更长（2.6 秒）；越往后船越小、预测线越短，到最后一关是 1 倍和 0.8 秒。
- 鱼雷击毁小型海盗船后会继续飞，可以一发多杀。
- 用的鱼雷不超过 par 数得三星。上一发的轨迹会以虚线保留，方便微调。
- 手机竖屏时关卡会自动旋转 90°（发射点在下方）。

## 内容

12 章 48 关，每章引入新机制：

| 章 | 名称 | 新机制 |
|---|---|---|
| 1 | 初次狩猎 | 行星引力、绕后、回旋、穿透多杀 |
| 2 | 碎石带 | 小行星（无引力，会撞碎鱼雷） |
| 3 | 巡逻舰队 | 往返巡逻 / 环绕轨道的海盗、正面护盾舰 |
| 4 | 奇点 | 黑洞、虫洞 |
| 5 | 海盗母舰 | 护卫编队、封锁线、3 血旋转护盾 Boss |
| 6 | 斥力星 | 把鱼雷推开的星：掀起鱼雷、打回马枪 |
| 7 | 反射镜 | 鱼雷碰到镜面会反弹，多次反弹的花式击杀 |
| 8 | 护航 | 民用货船不能打（打到即失败），最终关混合所有机制 |
| 9 | 引力弹弓 | 绕恒星公转的行星：从它身后掠过会被甩得更快（引力助推） |
| 10 | 磁场 | 洛伦兹力：鱼雷在磁场里速度方向匀速旋转、速率不变，越快弯越大 |
| 11 | 潮汐撕裂 | 进入洛希极限（红色虚线圈）后鱼雷一分为二，一发打两个方向 |
| 12 | 动量碰撞 | 撞动小行星（弹性碰撞、动量守恒），让它替你砸中海盗；能连锁传递 |

进度（星数、解锁）存在浏览器 localStorage。

## 目录

```
index.html        入口
css/style.css     界面样式
js/physics.js     物理核心（游戏、预测线、求助、求解器共用，固定步长，结果可复现；一次发射可含多枚鱼雷和被撞飞的小行星）
js/levels.js      关卡数据
js/audio.js       Web Audio 合成音效
js/i18n.js        中英文文字（界面、章节、关卡名和提示）
js/cards.js       物理小卡片（中英双语）
js/game.js        场景、输入、渲染、存档
tools/solve.js    关卡求解器：暴力扫描角度×力度×时机，验证每关可解并给出难度
proposal/         最初的 6 个创意提案页
```

## 开发

- 调试参数：`index.html?all` 解锁全部关卡；`index.html?lv=12` 直接进入第 12 关。
- 改关卡后运行求解器验证：

  ```
  node tools/solve.js          # 全部关卡
  node tools/solve.js 3 7      # 指定关卡
  node tools/solve.js 5 --fine # 更细的扫描
  ```

  输出每关是否可解、估算最少发射次数、命中率（越低越难）和示例解法。

## 关卡格式

坐标系 1600×900，详见 `js/levels.js` 顶部注释。示例：

```js
{ ch: 0, name: '借力', ammo: 5, par: 1, launch: [170, 720], tip: '……',
  planets: [{ x: 800, y: 480, r: 90, hue: 18 }],
  pirates: [{ x: 1220, y: 230 }] }
```
